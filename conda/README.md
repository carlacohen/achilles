Environments are created using the conda yml files.  

Note that for the integration environment, Harmony is installed via conda which will be version 0.1  

For the most up to date version of Harmony (currently 1.0.3) install via CRAN 

- load the conda environment
- launch R by typing "R" in the console (NB you need to not be in an R project directory for this to work)  
- use the following command to install harmony  

```
install.packages("harmony")
```
Type q() to exit R
